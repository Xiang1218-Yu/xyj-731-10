# 背景

读书会小程序：随着人们生活节奏的加快和信息的爆炸性增长，读书会作为一种集体学习和交流的方式逐渐受到欢迎。为了提高读书会的组织效率和参与度，读书会小程序将成为一个有益的工具。该小程序旨在为读书会提供统一的平台，方便组织者管理活动、参与者报名，并为参与者提供便捷的沟通和学习交流渠道。

# 功能

## 核心功能
- 活动管理：组织者可以轻松创建、编辑和取消读书会活动，管理活动的时间、地点、参与人数等信息。
- 参与报名：用户可以通过小程序浏览并报名参加感兴趣的读书会活动，提供简单而便捷的报名渠道。
- 书单推荐：小程序可以根据用户的阅读兴趣推荐相关书籍，促进读书会的多样化和深度。
- 学习资源分享：读书会成员可以在小程序上分享学习资源、笔记、心得等，推动学习交流和共享精神。
- 阅读打卡：支持每日阅读打卡，记录阅读历程。

## 新增功能迭代

### 1. 自定义报名表单字段
组织者在创建活动时可点击"添加自定义字段"，灵活配置报名者需要填写的信息：
- **支持字段类型**：单行文本、多行文本、单选、多选、整数数字、小数数字、开关选择、日期等
- **字段配置**：可设置字段名称、提示说明、是否必填、最大/最小长度、可选项等
- **动态渲染**：报名者填写表单时，根据组织者配置动态渲染对应输入控件
- **Excel导出**：后台导出报名名单时，自定义字段自动作为Excel列包含在导出文件中
- **字段排序**：支持拖拽调整字段顺序

### 2. 多媒体打卡
打卡功能从纯文字扩展为多媒体打卡：
- **图片打卡**：支持上传最多8张图片（已有功能增强）
- **语音打卡**：支持现场录制语音（最长60秒，MP3格式）或从聊天记录选择语音文件
- **位置打卡**：支持选择地理位置，记录打卡地点，可在地图中查看
- **语音播放**：打卡详情中支持在线播放语音
- 所有媒体文件自动上传至微信云存储，删除记录时自动清理云端文件

### 3. 报名审核状态流转与通知
- **报名方式设置**：组织者创建活动时可选择"直接通过"或"需审核"
- **待审核列表**：后台报名名单页支持按"待审核/报名成功/未过审"筛选
- **一键审核**：组织者可一键通过或拒绝报名，拒绝时可填写理由
- **批量审核**：支持勾选多条报名记录，批量通过或拒绝
- **人数上限**：设置人数上限后，达到上限自动截止报名
- **审核通知**：审核结果通过微信订阅消息通知报名者（需用户授权订阅）
- **状态流转**：待审核(0) → 报名成功(1) / 审核未过(99)

### 4. "我的"页面可视化数据统计
个人中心新增数据统计卡片和趋势图表：
- **活动报名统计**：总报名数、成功报名数、待审核数、已签到数
- **打卡统计**：累计打卡天数、参与打卡活动数
- **收藏统计**：我的收藏数量
- **30天打卡趋势图**：使用折线图展示最近30天打卡活跃度
- 卡片使用不同颜色区分，点击可跳转对应页面

### 5. 后台批量操作
后台管理界面支持批量操作，提升管理效率：
- **活动管理**：批量启用/停用、批量删除活动
- **报名名单**：批量审核通过/拒绝、批量删除报名记录
- **打卡管理**：批量启用/停用、批量删除打卡活动、批量删除打卡记录
- **用户管理**：批量启用/禁用、批量删除用户、批量设置标签
- 批量操作前有确认弹窗，防止误操作

### 6. 活动海报生成与分享
基于活动信息一键生成可分享的活动海报：
- **多模板选择**：提供3种海报模板（简约蓝、温馨橙、文艺绿）
- **海报内容**：活动封面、标题、时间、地点、小程序码
- **实时预览**：生成后可即时预览海报效果
- **保存到相册**：支持将海报保存到手机相册
- **微信分享**：支持直接分享给微信好友或朋友圈，海报作为分享封面

### 7. 用户标签与分组
后台用户管理系统新增标签和分组功能：
- **用户标签**：可为用户打上多个标签，如"活跃用户"、"资深书友"、"志愿者"等
- **用户分组**：可为用户设置分组，便于分类管理
- **管理员备注**：支持为用户添加管理员备注
- **标签筛选**：顶部标签栏支持按标签快速筛选用户
- **批量打标签**：支持批量为多个用户添加/移除/覆盖标签
- **标签聚合**：系统自动聚合所有标签并按使用频次排序展示

# 技术架构

## 前端（微信小程序原生开发）
- 框架：微信小程序原生框架
- 图表：wxcharts-min.js（折线图）
- 海报：wxa-plugin-canvas 海报生成插件
- 组件化：自定义表单组件、列表组件、弹窗组件等

## 后端（微信云开发）
- 云函数：Node.js
- 数据库：微信云数据库（NoSQL）
- 云存储：微信云存储（图片、语音、Excel文件）
- 订阅消息：微信订阅消息通知

## 数据库集合
- `activity`：活动表（含自定义表单配置 ACTIVITY_JOIN_FORMS）
- `activity_join`：活动报名表（含审核状态、签到状态）
- `enroll`：打卡活动表
- `enroll_join`：打卡记录表（支持图片、语音、位置）
- `enroll_user`：用户打卡统计表
- `user`：用户表（含标签 USER_TAGS、分组 USER_GROUP、备注 USER_MEMO）
- `fav`：收藏表
- `news`：公告表
- `product`：书单表
- `comment`：评论表
